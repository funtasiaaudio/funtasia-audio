Nyan Studioは、歌録りの流れに集中したWindows向けマルチトラック録音アプリです。録音、リージョン編集、ループ、モニターリバーブ、Stem書き出しまでをひとつの画面で扱えます。

The Studio

録音からStem書き出しまで、歌録りの流れをひとつに。

伴奏を読み込み、ボーカルを録音し、リージョンを直接編集。ルーラーからLoop範囲を作り、モニター専用リバーブで歌いやすい返しを作って、ミックスまたはボーカルStemを書き出せます。

Features

歌を録る流れに集中した機能。

ASIO / Audio Device

AUDIO SETTINGSから、ASIOを含むWindowsのオーディオデバイスを選択できます。

ソフトウェアモニタリング

録音される音はDryのまま、Nyan Studio経由でマイク入力をモニターできます。

Monitor Reverb

録音には焼き込まず、モニター音だけに歌唱用リバーブを加えられます。

リージョン編集

伴奏・ボーカルの移動、ボーカルの分割、範囲選択、選択リージョンのGlueに対応。

Loop / Repeat

ルーラーをドラッグしてLoop範囲を作成。Backing RegionのダブルクリックやRepeat再生にも対応します。

トラック操作

Mute / Solo、Rename、並べ替え、トラックごとのVolumeとPeak Meterを使用できます。

拍子と録音補助

3/4、4/4、6/8、BPM、メトロノーム、1小節カウントイン、横スクロール、横 / 縦Zoomに対応。

Mix / Vocal Stem Export

WAV / FLAC / AIFFの通常書き出しに加え、現在のRangeからボーカルトラックを個別Stemとして書き出せます。

セッション

.nyanstudio形式で保存・再開。Windowsでは専用のセッションファイルアイコンにも対応します。

Q&A

使い始める前によくある質問。

Nyan Studioでできること、モニタリング、書き出しについて、よくある質問をまとめました。

Nyan StudioはDAWですか？

フル機能の音楽制作DAWではなく、ボーカル録音、シンプルなリージョン編集、モニタリング、ループ、書き出しに集中したスタンドアロン・アプリです。

Nyan Studioは無料ですか？

はい。Windows向けに無料でダウンロードして使用できます。

ASIOに対応していますか？

はい。Nyan StudioはWindowsのASIOオーディオデバイスに対応しています。AUDIO SETTINGSから使用するASIOデバイスを選択できます。

USBマイクでも使えますか？

Windowsでオーディオ入力デバイスとして認識されていれば使用できます。Nyan Studio経由で自分の声を返したい場合はSoftware Monitoringも利用できます。

Monitor Reverbは録音にも入りますか？

入りません。Monitor Reverbはモニター経路だけにかかり、録音されるボーカルはDryのままです。

モニター中に声が二重に聞こえるのはなぜですか？

オーディオ機器側のDirect MonitoringとNyan StudioのSoftware Monitoringが同時に有効になっている可能性があります。二重に聞こえる、短いエコーのように感じる場合は、どちらか一方をOFFにしてください。Software Monitoring使用時はヘッドホンを推奨します。

何トラック使えますか？

Backing Trackは最大8本、Vocal Trackも最大8本まで使用できます。

Backing Trackはタイムライン上で動かせますか？

はい。BackingもRegionとして扱われ、ドラッグしてタイムライン上の開始位置を変更できます。

ボーカルはどこまで編集できますか？

Regionの移動、上半分からのSplit、Marquee範囲選択、選択RegionのGlue、Delete、Undo / Redoなどに対応しています。

ループ再生できますか？

はい。Ruler上をドラッグしてLoop Rangeを作り、RepeatをONにすると繰り返し再生できます。Backing Regionをダブルクリックして、その範囲をLoopにすることもできます。

対応している拍子は？

3/4、4/4、6/8に対応しています。

ボーカルStemを書き出せますか？

はい。Vocal Stem Exportで、現在のExport Rangeとオーディオ形式設定を使い、ボーカルトラックを個別に書き出せます。

対応している書き出し形式は？

WAV / FLAC / AIFF、44.1 / 48 kHzに対応しています。WAVは16-bit / 24-bit / 32-bit floatを選択できます。

セッションを保存して後から開けますか？

はい。.nyanstudio形式でSessionを保存し、後から続きを開けます。

VST / VST3プラグインは読み込めますか？

現在は対応していません。Nyan Studioは内蔵の録音、編集、モニタリング、書き出しワークフローに集中しています。
