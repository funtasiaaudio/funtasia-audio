반주를 불러오고 보컬을 녹음하세요. 리전을 바로 편집하고, 반복 재생과 내보내기에 공통 RANGE를 지정할 수 있습니다. 보컬 리버브로 모니터링하고 스테레오 믹스 또는 보컬 스템을 내보내세요.

Studio

녹음부터 스템 출력까지, 하나의 집중된 작업 흐름으로.

Nyan Studio는 보컬 녹음 흐름에 집중한 가벼운 멀티트랙 레코더입니다. 반주를 불러와 보컬을 녹음하고 리전을 편집한 뒤, 반복 재생과 내보내기에 공통 RANGE를 지정하세요. 모니터 전용 보컬 리버브를 사용하고 스테레오 믹스 또는 개별 보컬 스템을 내보낼 수 있습니다.

직접 편집

도구를 바꾸지 않고 바로 편집.

별도의 도구 전환이 필요 없습니다. 타임라인에서 Split, Shift 클릭 다중 선택, 함께 이동, Glue, Delete, RANGE 만들기를 바로 할 수 있습니다.

빠른 시작

설정부터 내보내기까지 다섯 단계.

분홍색 표시가 사용할 컨트롤이나 영역을 알려줍니다. 기본적인 녹음 흐름을 메인 화면만 보고도 이해할 수 있도록 설계했습니다.

1

먼저 Audio Settings를 설정하세요.

입력·출력 장치를 선택하고 사용할 오디오 버퍼 크기를 설정하세요. Nyan Studio는 이전 오디오 장치 설정을 기억합니다. 드라이버 자체 패널에서 버퍼 크기를 관리하는 경우 OPEN DRIVER CONTROL PANEL로 패널을 열 수 있습니다.

2

반주 트랙을 추가하세요.

Add Backing 버튼으로 세션에 반주를 불러오세요. 지원되는 오디오 파일을 타임라인에 드래그해 추가할 수도 있습니다.

3

Record를 누르고 노래하세요!

VOX 트랙을 녹음 대기 상태로 만든 뒤 분홍색 Record 버튼을 누르세요. 필요에 따라 Count-In, Software Monitoring, Monitor Reverb를 사용할 수 있습니다.

4

녹음이 완료되었습니다.

녹음한 테이크는 VOX 리전으로 표시됩니다. 클릭해 하나를 선택하고 Shift 클릭으로 선택을 추가하거나 해제한 뒤, 선택한 리전을 함께 이동하거나 삭제하세요. 같은 VOX 트랙의 리전은 Glue / Merge로 합칠 수도 있습니다.

5

RANGE를 지정하고 내보내세요.

눈금자 또는 빈 편곡 영역을 가로질러 드래그해 RANGE를 만드세요. Backing 리전이나 VOX 리전 아래쪽을 더블 클릭해 지정할 수도 있습니다. 필요하면 IN / OUT 삼각형 핸들을 조정한 뒤 Export를 누르세요.

하나의 RANGE가 반복 재생과 내보내기에 함께 적용됩니다. 눈금자를 더블 클릭하면 해제됩니다.

Features

녹음 흐름에 집중한 기능.

ASIO 및 오디오 장치

ASIO를 포함한 Windows 오디오 장치를 선택하고 버퍼 크기를 설정하세요. 필요하면 드라이버의 기본 제어판을 다시 열 수 있으며, 이전 오디오 장치 설정은 다음 실행 때 복원됩니다.

Software Monitoring

녹음되는 보컬은 드라이 상태로 유지하면서 Nyan Studio를 통해 마이크 소리를 모니터링합니다.

Monitor Reverb

녹음 파일에는 리버브를 적용하지 않고 모니터 경로에만 보컬용 리버브를 더합니다.

멀티 리전 편집

클릭으로 VOX 리전을 선택하고 Shift 클릭으로 여러 리전을 선택한 뒤 함께 이동하거나 삭제할 수 있습니다. 같은 트랙의 선택 항목은 Glue / Merge로 합칠 수 있습니다.

공통 RANGE

하나의 RANGE가 반복 재생과 내보내기를 제어합니다. 눈금자, 리전, 빈 편곡 영역에서 만들고 IN / OUT 핸들로 크기를 조정하세요. 눈금자를 더블 클릭하면 해제됩니다.

트랙 컨트롤

트랙별 음량과 피크 미터를 확인하고 음소거, 솔로, 이름 변경, 순서 변경을 할 수 있습니다.

박자 및 탐색

3/4, 4/4, 6/8 박자와 BPM, 메트로놈, 1마디 카운트인, 가로 스크롤, 가로 및 트랙 높이 줌을 사용할 수 있습니다.

믹스 및 보컬 스템

WAV, FLAC, AIFF로 내보내거나 현재 RANGE를 기준으로 보컬 스템을 개별 렌더링할 수 있습니다.

세션 작업

.nyanstudio 형식으로 작업을 저장하고 다시 열 수 있으며, Windows 전용 세션 파일 아이콘이 제공됩니다.

Version 1.1.2

더 세밀해진 오디오 설정. 더 빠른 리전 편집.

버전 1.1.2에서는 선택 가능한 오디오 버퍼 크기, 이전 오디오 장치 설정 복원, 드라이버 제어판 열기, 드라이버가 관리하는 ASIO 장치의 버퍼 재동기화 기능이 추가되었습니다. VOX 편집에는 Shift 클릭 다중 선택, 함께 이동·삭제, 같은 트랙 Glue / Merge, 빈 편곡 영역에서 RANGE 만들기가 추가되었습니다.

FUNtasia의 밝은 한 켠

실행하는 순간부터 가볍게 느껴지도록.

Nyan Studio는 FUNtasia Audio 세계의 일부이면서 새잎처럼 산뜻한 초록색을 담았습니다. 목적이 분명하고 친근한 작은 녹음 공간입니다.

자주 묻는 질문

시작하기 전에 확인하세요.

Nyan Studio의 기능, 모니터링, 오디오 버퍼 설정, 공통 RANGE를 간단히 안내합니다.

Nyan Studio는 DAW인가요?

Nyan Studio는 종합 음악 제작용 DAW가 아닙니다. 보컬 녹음, 간단한 리전 편집, 모니터링, 반복 재생과 내보내기에 집중한 독립 실행형 앱입니다.

Nyan Studio는 무료인가요?

네. Nyan Studio는 Windows에서 무료로 다운로드해 사용할 수 있습니다.

ASIO를 지원하나요?

네. AUDIO SETTINGS에서 ASIO 장치를 선택하세요. 버퍼 크기 선택 기능이 있으며 이전 오디오 장치 설정도 기억합니다.

ASIO 버퍼 크기를 변경할 수 없는 이유는 무엇인가요?

일부 ASIO 드라이버는 제조사 제어판에서만 버퍼 크기를 변경할 수 있습니다. AUDIO SETTINGS에서 OPEN DRIVER CONTROL PANEL을 사용하세요. 패널을 닫으면 Nyan Studio가 현재 버퍼 크기를 다시 동기화합니다.

USB 마이크를 사용할 수 있나요?

Windows에서 오디오 입력 장치로 인식하면 사용할 수 있습니다. 마이크 소리를 Nyan Studio로 듣고 싶다면 Software Monitoring을 사용하세요.

모니터 리버브가 보컬 녹음에 포함되나요?

아니요. Monitor Reverb는 모니터 경로에만 적용되며 녹음된 보컬은 드라이 상태입니다.

모니터링할 때 목소리가 두 번 들리는 이유는 무엇인가요?

오디오 장치의 하드웨어 Direct Monitoring과 Nyan Studio의 Software Monitoring이 동시에 켜져 있을 수 있습니다. 소리가 겹치거나 짧은 에코가 들리면 둘 중 하나를 끄세요. 헤드폰 사용을 권장합니다.

트랙은 몇 개까지 사용할 수 있나요?

반주 트랙은 최대 8개, 보컬 트랙은 최대 8개까지 지원합니다.

RANGE는 어떻게 작동하나요?

RANGE는 반복 재생과 내보내기에 함께 사용됩니다. 눈금자나 빈 편곡 영역을 드래그해 만들고, Backing 리전 또는 VOX 리전 아래쪽을 더블 클릭해 해당 구간에 맞출 수 있습니다. IN / OUT 삼각형 핸들로 크기를 조정하고 눈금자를 더블 클릭해 해제하세요.

보컬 편집 기능에는 무엇이 있나요?

VOX 리전 아래쪽을 드래그해 이동하고 위쪽을 더블 클릭해 Split할 수 있습니다. 가장자리를 트림하고 Shift 클릭으로 여러 리전을 선택해 함께 이동·삭제하거나 같은 트랙에서 Glue / Merge할 수 있으며 Undo / Redo도 지원합니다.

보컬 스템을 내보낼 수 있나요?

네. Vocal Stem Export는 현재 RANGE와 오디오 형식 설정을 사용해 보컬 트랙을 각각 렌더링합니다.

어떤 박자를 지원하나요?

3/4, 4/4, 6/8을 지원합니다.

어떤 형식으로 내보낼 수 있나요?

44.1 또는 48 kHz의 WAV, FLAC, AIFF를 지원합니다. WAV는 16-bit, 24-bit, 32-bit float로 내보낼 수 있습니다.

세션을 저장하고 다시 열 수 있나요?

네. 세션은 .nyanstudio 형식으로 저장되며 나중에 다시 열 수 있습니다.

VST 또는 VST3 플러그인을 불러올 수 있나요?

아니요. 현재 Nyan Studio는 서드파티 플러그인 호스팅보다 내장된 녹음, 편집, 모니터링, 내보내기 작업 흐름에 집중합니다.

녹음 후

Nyan Studio에서 녹음하고, 믹스 결과는 Nyan Player에서 확인하세요.

믹스 엔지니어에게서 보컬 믹스가 돌아오면 Nyan Player에서 간편하게 들어보고 확인할 수 있습니다. Nyan Studio의 시각 스타일을 적용한 FUNtasia Player로, 녹음부터 감상까지 같은 세계관을 이어갑니다. EQ, 노멀라이즈, 리미팅, 새추레이션을 추가하지 않고 그대로 재생합니다.
