FUNtasia의 악기를 손에 넣는 순간, 당신은 연금술사가 됩니다. FUNtasia가 만든 악기에서 시작해, 컨트롤을 조정하며 자신만의 도구로 완성해 보세요.

FUNtasia는 상상 속 오디오 악기를 실제 창작 작업에 쓸 수 있는 도구로 구현하는 세계입니다. 플러그인, 앱, Rack, 프리셋, 음악, 영상, 웹사이트까지 모두 하나의 세계에 속해 있습니다.

Curve Distortion

FUN WaveShaper

커브를 그리고, 디스토션을 직접 조형하세요.

FUN WaveShaper는 Image-Line의 Fruity WaveShaper가 보여 준 직관적인 커브 편집 방식에서 영감을 받아 FUNtasia Audio가 독자적으로 개발한 웨이브셰이퍼입니다. 노드를 추가하고 커브를 구부리며, 새츄레이션부터 클리핑과 웨이브폴딩까지 원하는 전송 특성을 그릴 수 있습니다.

내부 커브 처리와 오버샘플링은 64-bit 부동소수점(double precision) 연산을 사용합니다. 호스트가 32-bit float 오디오를 전달하더라도 내부 처리는 64-bit float로 수행됩니다. PRE / POST, Dry / Wet MIX, 오버샘플링, Minimum / Linear Phase를 선택해 자신만의 사운드를 만들어 보세요.

Fruity WaveShaper의 커브 편집 개념에서 영감을 얻은 독립 개발 제품입니다. Image-Line과 제휴 관계가 없습니다.

Design Principles

의도를 담아 설계합니다.

01

아날로그에서 배우고,
디지털을 위해 설계합니다.

소리에 유용한 동작을 배우고 디지털 환경에 맞는 악기를 만듭니다.

02

소리에 필요한 것만.

모든 처리는 음악적 또는 기능적인 이유가 있을 때만 더합니다.

03

의미 있는 선택은 사용자에게.

자신의 소리와 작업 방식에 맞춰 악기의 성격을 조정할 수 있도록 중요한 선택을 가까이에 둡니다.

04

기본값에는 경험을,
컨트롤에는 자유를.

실제 제작 경험을 담은 설정에서 출발해 원하는 소리로 나아갈 수 있습니다.

Our Story

그 자체로 하나의 세계.

FUNtasia Audio는 질문 하나에서 시작했습니다. 처음부터 디지털 환경을 위해 오디오 도구를 설계하면 어떤 모습일까?

소리가 움직이는 방식에서 영감을 얻고 디지털 설계의 가능성을 따라갑니다. 각 악기는 무엇을 하고, 사용할 때 어떤 느낌을 줄지 분명한 생각에서 출발합니다.

플러그인, 앱, Rack, 프리셋, 음악, 영상, 웹사이트는 하나의 상상 속 세계에 속합니다. 실제 세션에서 쓸 수 있으면서 시작할 자리를 제공하고 다음 단계를 직접 만들어갈 여지도 남깁니다.

취향이나 워크플로가 달라질 때마다 도구를 바꾸는 대신, 악기의 성격을 자신에게 맞게 조정할 수 있도록 필요한 부분을 열어 둡니다. 개발 환경처럼 복잡해지지 않으면서도 나만의 방식으로 다듬을 수 있습니다.

FUNtasia는 저마다의 성격과 목적을 지닌 도구를 계속 만들어 또 하나의 선택지를 더합니다.
