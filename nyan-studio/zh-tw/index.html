工作室

從錄音到 Stem，一套專注的工作流程。

Nyan Studio 是一款以人聲錄音流程為核心的輕量多軌錄音軟體。載入伴奏、錄製人聲、編輯片段，再設定 Repeat 與 Export 共用的 RANGE。可透過專用的人聲混響監聽，最後匯出立體聲混音或個別人聲 Stem。

直接編輯

不用切換工具，直接編輯。

不必切換工具，就能在時間軸上直接 Split、Shift 點選多個片段、群組移動、Glue、Delete，以及建立 RANGE。

快速開始

從設定到匯出，只要五個步驟。

粉紅色標記會指出要使用的控制項或區域。Nyan Studio 的主畫面讓你直接理解基本錄音流程。

1

先設定 Audio Settings。

選擇輸入與輸出裝置，再設定所需的音訊緩衝區大小。Nyan Studio 會記住上次的音訊裝置設定。若緩衝區由驅動程式面板管理，可使用 OPEN DRIVER CONTROL PANEL 開啟面板。

2

加入伴奏。

按下 Add Backing 將伴奏載入工作階段，也可以把支援的音訊檔拖曳到時間軸。

3

按下 Record，開始演唱！

啟用 VOX 軌的錄音待命，再按下粉紅色 Record 按鈕。可依需求使用 Count-In、Software Monitoring 與 Monitor Reverb。

4

錄音完成。

錄音內容會顯示為 VOX 片段。點選單一片段，再以 Shift 點選加入或取消其他片段，接著一起移動或刪除。相同 VOX 軌上的片段也能透過 Glue / Merge 合併。

5

設定 RANGE 並匯出。

在尺規或編曲空白區域上拖曳即可建立 RANGE。也可雙擊 Backing 片段或 VOX 片段下半部來設定。需要時調整 IN / OUT 三角形控制點，再按下 Export。

同一個 RANGE 會套用於 Repeat 播放與 Export。雙擊尺規即可清除。

功能

專注於錄音流程。

ASIO 與音訊裝置

選擇包含 ASIO 在內的 Windows 音訊裝置、設定緩衝區大小，必要時重新開啟驅動程式原生控制面板，並在下次啟動時還原上次的音訊裝置設定。

Software Monitoring

透過 Nyan Studio 監聽麥克風，同時讓錄下的人聲保持乾聲。

Monitor Reverb

只在監聽路徑加入適合人聲的混響，不會將效果寫入錄音。

多片段編輯

點選一個 VOX 片段，再以 Shift 點選建立多重選取，便能一起移動或刪除。相同軌道的選取片段可以使用 Glue / Merge 合併。

共用 RANGE

同一個 RANGE 控制 Repeat 與 Export。可從尺規、片段或編曲空白區域建立，使用 IN / OUT 控制點調整範圍，雙擊尺規即可清除。

軌道控制

可靜音、獨奏、更名與重新排列軌道，並查看各軌音量與峰值電平。

節拍與導覽

支援 3/4、4/4 或 6/8 拍號、BPM、節拍器、一小節預備拍、水平捲動，以及水平／軌道高度縮放。

混音與人聲 Stem

可匯出 WAV、FLAC、AIFF，或依目前的 RANGE 個別輸出人聲 Stem。

工作階段管理

使用 .nyanstudio 格式儲存與重新開啟專案，並提供專用的 Windows 工作階段檔案圖示。

常見問題

開始之前，先看看常見問題。

快速了解 Nyan Studio 的用途、監聽方式、音訊緩衝區設定，以及共用 RANGE 的運作方式。

Nyan Studio 是 DAW 嗎？

Nyan Studio 並非完整的音樂製作 DAW，而是一款專注於人聲錄音、簡易片段編輯、監聽、Repeat 與 Export 的獨立應用程式。

Nyan Studio 免費嗎？

是的。Nyan Studio 可在 Windows 免費下載與使用。

Nyan Studio 支援 ASIO 嗎？

支援。請在 AUDIO SETTINGS 選擇 ASIO 裝置。Nyan Studio 也提供緩衝區大小選擇，並會記住上次的音訊裝置設定。

為什麼 Nyan Studio 無法變更 ASIO 緩衝區大小？

部分 ASIO 驅動程式只能透過製造商的控制面板變更緩衝區大小。請在 AUDIO SETTINGS 使用 OPEN DRIVER CONTROL PANEL；關閉面板後，Nyan Studio 會重新同步目前的緩衝區大小。

可以使用 USB 麥克風嗎？

可以，只要 Windows 將它識別為音訊輸入裝置即可。若要透過 Nyan Studio 聽見麥克風聲音，可使用 Software Monitoring。

監聽混響會錄進人聲嗎？

不會。Monitor Reverb 只套用於監聽路徑，錄下的人聲仍是乾聲。

為什麼監聽時會聽到兩層人聲？

音訊裝置的硬體 Direct Monitoring 可能與 Nyan Studio 的 Software Monitoring 同時啟用。若聽到重疊或短暫回音，請關閉其中一種監聽方式。建議使用耳機。

最多可以使用幾軌？

最多支援 8 軌伴奏與 8 軌人聲。

RANGE 如何運作？

RANGE 同時供 Repeat 與 Export 使用。在尺規或編曲空白區域拖曳即可建立；雙擊 Backing 片段或 VOX 片段下半部，可將範圍設為該片段。拖曳 IN / OUT 三角形控制點即可調整，雙擊尺規可清除。

有哪些人聲編輯工具？

拖曳 VOX 片段下半部可移動，雙擊上半部可 Split，也能修剪片段邊緣。以 Shift 點選多個片段後可一起移動或 Delete，同軌選取內容可 Glue / Merge，並支援 Undo / Redo。

可以匯出人聲 Stem 嗎？

可以。Vocal Stem Export 會依目前的 RANGE 與音訊格式設定，逐軌輸出人聲。

支援哪些拍號？

支援 3/4、4/4 與 6/8。

支援哪些匯出格式？

支援 44.1 或 48 kHz 的 WAV、FLAC、AIFF。WAV 可匯出為 16-bit、24-bit 或 32-bit float。

可以儲存並重新開啟工作階段嗎？

可以。工作階段會以 .nyanstudio 格式儲存，之後可重新開啟。

Nyan Studio 可以載入 VST 或 VST3 插件嗎？

目前不支援。Nyan Studio 專注於內建的錄音、編輯、監聽與匯出流程，尚未提供第三方插件宿主功能。

錄音之後

在 Nyan Studio 錄音，再用 Nyan Player 檢查混音成果。

混音工程師交回人聲混音後，可用 Nyan Player 輕鬆聆聽與確認成果。它是採用 Nyan Studio 視覺風格的 FUNtasia Player，讓錄音到聆聽延續同一個世界觀。播放訊號保持直接，不額外加入 EQ、正規化、Limiter 或 Saturation。
