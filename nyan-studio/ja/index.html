Nyan Studioは、歌録りの流れに集中したWindows向けマルチトラック録音アプリです。録音、リージョン編集、共通RANGE、モニターリバーブ、Stem書き出しまでをひとつの画面で扱えます。

The Studio

録音からStem書き出しまで、歌録りの流れをひとつに。

伴奏を読み込み、ボーカルを録音し、リージョンを直接編集。RepeatとExportで共通のRANGEを決め、モニター専用リバーブで歌いやすい返しを作って、ミックスまたはボーカルStemを書き出せます。

Direct Editing

ツール切り替えなしで、そのまま編集。

ツール切り替えは不要。Split、Shift+クリックの複数選択、まとめて移動・削除、Glue / Merge、RANGE作成までタイムライン上で直接操作できます。

Quick Start

録音から書き出しまで、5ステップ。

ピンクの囲みが、そのステップで使う場所です。基本の歌録りは、この5枚を上から見れば進められます。

1

まずはオーディオ設定。

AUDIO SETTINGSで入力・出力デバイスを選び、使いたいAUDIO BUFFERを設定します。前回のオーディオ設定は次回起動時に復元されます。ドライバー側でBuffer Sizeを管理するASIOでは、OPEN DRIVER CONTROL PANELから設定画面を開けます。

2

追加ボタンでオケを追加。

♪＋のAdd Backingボタンから伴奏を読み込みます。対応オーディオをタイムラインへドラッグ＆ドロップして追加することもできます。

3

録音ボタンで歌いましょう！

VOXトラックをREC ARMして、ピンクの録音ボタンを押せば録音開始。必要に応じてCOUNT-IN、MONITOR、REVERBも使えます。

4

録音成功！

録った声はVOXリージョンとして表示されます。クリックで単体選択、Shift+クリックで選択を追加／解除。複数選択したリージョンはまとめて移動・削除でき、同じVOXトラック内ならGlue / Mergeで結合できます。

5

RANGEを決めて、エクスポート。

上のルーラー、またはアレンジビューの空白を横にドラッグしてRANGEを作れます。Backingリージョン、またはVOXリージョン下半分のダブルクリックでも設定できます。必要ならIN / OUTの三角ハンドルで調整し、Exportボタンを押せば完成です。

RANGEはRepeatとExportで共通です。ルーラーをダブルクリックするとRANGEを消去できます。

Features

歌を録る流れに集中した機能。

ASIO / Audio Device

AUDIO SETTINGSからASIOを含むWindowsのオーディオデバイスを選択し、Buffer Sizeを設定できます。前回の設定を次回起動時に復元し、必要に応じてドライバー標準のControl Panelも開けます。

ソフトウェアモニタリング

録音される音はDryのまま、Nyan Studio経由でマイク入力をモニターできます。

Monitor Reverb

録音には焼き込まず、モニター音だけに歌唱用リバーブを加えられます。

複数リージョン編集

クリックで単体選択、Shift+クリックで複数選択。選択したリージョンをまとめて移動・削除でき、同じVOXトラック内ならGlue / Mergeで結合できます。

共通RANGE

RepeatとExportは同じRANGEを使用。ルーラー、リージョン、アレンジビューの空白から作成し、IN / OUT三角で長さを調整、ルーラーのダブルクリックで解除できます。

トラック操作

Mute / Solo、Rename、並べ替え、トラックごとのVolumeとPeak Meterを使用できます。

拍子・ナビゲーション

3/4、4/4、6/8、BPM、メトロノーム、1小節カウントイン、横スクロール、横 / 縦Zoomに対応。

Mix / Vocal Stem Export

WAV / FLAC / AIFFの通常書き出しに加え、現在のRANGEからボーカルトラックを個別Stemとして書き出せます。

セッション

.nyanstudio形式で保存・再開。Windowsでは専用のセッションファイルアイコンにも対応します。

Q&A

使い始める前によくある質問。

Nyan Studioでできること、モニタリング、Buffer Size、共通RANGE、書き出しについてまとめました。

Nyan StudioはDAWですか？

フル機能の音楽制作DAWではなく、ボーカル録音、シンプルなリージョン編集、モニタリング、Repeat、書き出しに集中したスタンドアロン・アプリです。

Nyan Studioは無料ですか？

はい。Windows向けに無料でダウンロードして使用できます。

ASIOに対応していますか？

はい。AUDIO SETTINGSから使用するASIOデバイスを選択できます。Buffer Sizeの選択にも対応し、前回のオーディオ設定は次回起動時に復元されます。

Nyan StudioからBuffer Sizeを変えられないASIOがあります。

一部のASIOドライバーはメーカー側Control PanelからのみBuffer Sizeを変更できます。その場合はAUDIO SETTINGSのOPEN DRIVER CONTROL PANELを使ってください。Control Panelを閉じたあと、Nyan Studioが実際のBuffer Sizeへ再同期します。

USBマイクでも使えますか？

Windowsでオーディオ入力デバイスとして認識されていれば使用できます。Nyan Studio経由で自分の声を返したい場合はSoftware Monitoringも利用できます。

Monitor Reverbは録音にも入りますか？

入りません。Monitor Reverbはモニター経路だけにかかり、録音されるボーカルはDryのままです。

モニター中に声が二重に聞こえるのはなぜですか？

オーディオ機器側のDirect MonitoringとNyan StudioのSoftware Monitoringが同時に有効になっている可能性があります。二重に聞こえる場合はどちらか一方をOFFにしてください。Software Monitoring使用時はヘッドホンを推奨します。

何トラック使えますか？

Backing Trackは最大8本、Vocal Trackも最大8本まで使用できます。

RANGEはどう使いますか？

RANGEはRepeatとExportで共通です。ルーラーまたはアレンジビューの空白を横ドラッグして作成、BackingリージョンまたはVOXリージョン下半分をダブルクリックしてリージョン全体に設定、IN / OUT上部の三角をドラッグして長さを調整できます。ルーラーをダブルクリックすると解除できます。

ボーカルはどこまで編集できますか？

VOX下半分のドラッグ移動、上半分のダブルクリックSplit、端のTrim、Shift+クリック複数選択、まとめて移動・Delete、同一トラック内のGlue / Merge、Undo / Redoに対応しています。

ボーカルStemを書き出せますか？

はい。Vocal Stem Exportで、現在のRANGEとオーディオ形式設定を使い、ボーカルトラックを個別に書き出せます。

対応している拍子は？

3/4、4/4、6/8に対応しています。

対応している書き出し形式は？

WAV / FLAC / AIFF、44.1 / 48 kHzに対応しています。WAVは16-bit / 24-bit / 32-bit floatを選択できます。

セッションを保存して後から開けますか？

はい。.nyanstudio形式でSessionを保存し、後から続きを開けます。

VST / VST3プラグインは読み込めますか？

現在は対応していません。Nyan Studioは内蔵の録音、編集、モニタリング、書き出しワークフローに集中しています。

After Recording

録ったあとも、同じ世界で聴く。

Nyan Studioでヴォーカルを録音し、ミックス担当から仕上がったヴォーカルミックスや完成音源を受け取ったら、Nyan Playerでそのまま確認できます。Nyan PlayerはFUNtasia Playerをベースに、Nyan Studioの世界観へGUIを再設計したシンプルなスタンドアロン・プレイヤー。録音から確認まで、見た目の統一感を保ったまま使えます。再生音にはEQ、Normalization、Limiter、Saturationなどを追加しません。
